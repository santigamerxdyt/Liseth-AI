# Hermes Agent Integration

## 🎯 Objetivo
Configurar, monitorear y extender el runtime de Hermes Agent (`app/services/hermes_adapter.py`).

## ⚙️ Procedimiento
1. Registrar agentes nombrados con roles y prompts especializados.
2. Gestionar la memoria aislada de la sesión por usuario.
3. Validar permisos de herramientas antes de su despacho.
