# Workspace Automation & Office Productivity Skill

## Overview
The `workspace-automation` skill empowers Liseth to construct advanced spreadsheet formulas, consulting report architectures, executive slide presentations, and academic blueprints.

## Core Capabilities
1. **Spreadsheet Formulas & Modeling (`excel_formula`)**:
   - Advanced lookup: `BUSCARX / XLOOKUP`, `INDICE(COINCIDIR) / INDEX(MATCH)`.
   - Multi-conditional aggregations: `SUMAR.SI.CONJUNTO / SUMIFS`, `CONTAR.SI.CONJUNTO / COUNTIFS`.
   - Dynamic arrays: `FILTRAR / FILTER`, `ORDENAR / SORT`, `UNICOS / UNIQUE`.
   - Financial functions: `PAGO / PMT`, `TIR / IRR`, `VNA / NPV`.
2. **Consulting & Academic Report Blueprints (`report_blueprint`)**:
   - Outlines structured consulting reports (Executive Summary, Problem Diagnosis, Strategic Alternatives, Implementation Roadmap, ROI).
   - Academic Essay / Thesis structures (Hook, Central Thesis, Evidence Arguments, Counterarguments & Refutations, Academic Conclusion).
3. **Executive Presentation Outline (`presentation_deck`)**:
   - Slide-by-slide structure with speaker notes, key takeaways, and visual layout recommendations.
