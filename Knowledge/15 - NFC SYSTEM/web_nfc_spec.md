# 📶 WEB NFC SPECIFICATION // PROTOCOLO DE COMUNICACIÓN CONTACTLESS

- **Estándar:** W3C Web NFC Candidate Recommendation.
- **Hardware Físico:** Chips NFC Forum Type 2 (NTAG213, NTAG215, NTAG216) y Type 4 operando a 13.56 MHz.
- **Registros NDEF:** Codificación en UTF-8 para texto, URLs y tarjetas vCard.
