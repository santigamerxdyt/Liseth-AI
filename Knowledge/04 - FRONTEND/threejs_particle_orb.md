# 🌐 THREE.JS PARTICLE ORB // NÚCLEO HOLOGRÁFICO DE IA

## ⚙️ Especificación Gráfica
- **Motor:** Three.js r128 en WebGL Canvas.
- **Geometría:** 2,400 partículas organizadas en doble capa icosaédrica concéntrica con rotación sinusoidal independiente.
- **Reactividad Acústica:** Conectado al `AudioContext` de la Web Audio API para alterar el radio y la dispersión de las partículas según la frecuencia vocal del usuario.
