# 🛠️ SKILLS REGISTRY // REGISTRO DE CAPACIDADES DINÁMICAS

Las skills representan unidades atómicas de ejecución que los agentes pueden invocar a través del [[action_dispatcher]]. Incluyen herramientas de inspección del workspace, cálculo financiero, análisis de bases de datos, operaciones NFC y formateo de documentos ejecutivos.
