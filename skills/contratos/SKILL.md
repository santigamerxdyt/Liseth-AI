# Procedimiento de Ejecución
1. Solicita a Santiago el nombre del cliente, tipo de servicio, monto acordado, moneda y fecha límite de entrega.
2. Redacta las cláusulas esenciales: objeto del contrato, entregables específicos, términos y plazos de pago, confidencialidad y resolución de desacuerdos.
3. Presenta el borrador completo en formato Markdown para la aprobación de Santiago.
4. Una vez aprobado, guarda el documento en la carpeta `archivos_creados/` o solicita confirmación antes de enviarlo.
